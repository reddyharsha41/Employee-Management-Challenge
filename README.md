# Employee Management Challenge

## 📌 Project Overview

The **Employee Management Challenge** is a simple console-based C++ program used to manage employee information.

This project allows the user to add employees, display employee details, search for an employee, and manage basic employee records.

It is designed for beginners to practice important **C++ Object-Oriented Programming (OOP)** concepts.

## 🎯 Features

* Add employee details
* Display all employees
* Search for an employee
* Update employee information
* Delete employee information
* Calculate/display employee salary
* Simple menu-driven interface

## 🛠️ Technologies Used

* **C++**
* Object-Oriented Programming (OOP)
* Standard C++ libraries

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone <your-github-repository-link>
```

### 2. Open the project

Open the project folder in **VS Code** or any C++ IDE.

### 3. Compile the program

Using g++:

```bash
g++ main.cpp -o employee
```

### 4. Run the program

Windows:

```bash
employee.exe
```

Linux/macOS:

```bash
./employee
```
